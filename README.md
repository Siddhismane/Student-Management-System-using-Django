# 🎓 Student Management System (Django Project)

This is a full-stack **Student Management System** built using the **Django framework**, designed to manage student registrations, course enrollments, and administrative tasks. It features user authentication, dynamic dashboards, CRUD operations for student data, and a clean frontend using **HTML, CSS, JS, Bootstrap**, and **Django Templates (Jinja2)**.

---

## 📌 Project Features

### 🔐 Authentication
- **Admin login/logout** system.
- **Student registration** with login access.

### 🏠 Home Page
- Introduction about the institute.
- Advertisements and important highlights.
- Navigation bar with page links.
